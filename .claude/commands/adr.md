Create an Architecture Decision Record for: **$ARGUMENTS**

1. Find the next number in `docs/decisions/` (format `NNNN-kebab-title.md`).
2. Use `docs/templates/adr.md`. Fill in context from the current code and README's "Why this design" table.
3. List at least two options considered, with trade-offs (cost matters, because this runs on a ~$15/month box).
4. Set status to `Proposed` unless the user says it is accepted.
5. Add the new ADR to the index in `docs/decisions/README.md`.
