Write a feature spec for: **$ARGUMENTS**

1. Copy the structure of `docs/templates/feature-spec.md`.
2. Ground every section in the actual code: name the real models, routes, components and files.
3. For AI features, also fill in an `docs/templates/ai-prompt.md` section with the exact output JSON shape.
4. Save it as `docs/specs/<kebab-case-title>.md` (create the folder if needed).
5. Add a matching item to the **Inbox** in `BACKLOG.md` that links to the spec.
6. List any open questions at the end. Do not guess product decisions; ask.
